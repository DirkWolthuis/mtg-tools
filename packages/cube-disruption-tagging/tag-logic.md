# Disruption tags explainer

## Structure of tag:

`{modifier}{disruption_type}:${target}

## Types of disruption:

- Hand hate -> forces opponent to discard card. Tag uses `hh`
- Stack interaction -> interacts with spells on the stack. Tag uses `si`
- Removal -> interacts with permanents on the battlefield. Tag uses `r`

## Modifiers

- Conditional -> disruption is not always useable (e.g. lets opponent pay cost to nullify effect, or specifies a specific creature type) Tag uses `c`
- Soft -> temporarily disrupts target (e.g. returns spell or creature to opponents hand or deck). Tag uses `s`

## Targets

Describes the target for the disruption. It reflects what the rule text of the card describes and can be a composite type. For example noncreature.
